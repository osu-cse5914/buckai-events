## User Flows

### Discover Recommended Content

1. The user logs in to the application.
2. The user lands on the Home Page (Social OSU).
3. The Home Page displays recommended events and gigs based on the user's preferences and activity.
4. The user browses the Recommended, Popular, and Upcoming sections.
5. The user clicks on an event or gig card to view its details.
6. The user may bookmark, sign up for, or apply to the selected item.

### Browse and Filter Events or Gigs

1. The user opens the Events Page or Gigs Page from the navigation bar.
2. The page displays all ongoing events or gigs.
3. By default, items are sorted by date/time (newest first).
4. The user applies sorting options, such as date/time, number of applications, or number of bookmarks.
5. The user uses category filters to refine the results.
6. The user clicks on a card to open the corresponding detail view.
7. The user may bookmark, sign up for, or apply to the selected item.

### Search for Events and Gigs

1. The user enters a keyword into the global search input.
2. The application opens the Search Results Page.
3. The page displays matching events and gigs.
4. The user browses the results and selects a relevant card.
5. The user opens the corresponding detail view and may bookmark, sign up for, or apply to the selected item.

### Manage Personal Content in My Page

1. The user opens My Page from the navigation bar.
2. The page displays the user's Collections, Applications, and Created sections.
3. In Collections, the user may remove saved events or gigs.
4. In Applications, the user may withdraw from signed-up events or applied gigs.
5. In Created, the user may open a created event or gig for editing or delete it directly.

### Chat with AI Agent

1. The user clicks the AI Agent button in the top navigation bar.
2. The application opens the AI Agent Page.
3. The user starts a new conversation or selects a previous conversation from the history sidebar.
4. The user sends a message to the AI agent.
5. The AI agent responds in the chat area.
6. The user may continue the conversation or return to a previous chat session later.
