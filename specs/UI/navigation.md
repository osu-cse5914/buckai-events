## Global Navigation

The top navigation bar is visible on all main pages after login.

From left to right:

- Social OSU
  - navigates to the Home Page
  - displays AI-recommended events and gigs

- Events
  - displays all ongoing events
  - not ranked by AI

- Gigs
  - displays all ongoing gigs
  - not ranked by AI

- My Page
  - includes:
    - collections (saved events and gigs)
    - applications (events/gigs the user joined or applied to)
    - created events and gigs

- Search Input
  - a global search input located in the top navigation bar
  - allows users to search events and gigs using keywords
  - opens the Search Results Page

- AI Agent Button
  - located next to the search input and profile icon
  - opens a dedicated AI Agent Page
  - allows users to chat with the AI assistant separately from the traditional search flow

- Profile
  - provides access to user account information and settings
