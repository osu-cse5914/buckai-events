# User Flows

**Status**: Draft
**Related spec**: [`app-pages.md`](app-pages.md)

### Discover Recommended Content in Featured

1. The user logs in to the application.
2. The user lands on `Featured`.
3. `Featured` displays personalized event and gig recommendations.
4. The user browses discovery modules such as `Recommended`, `Popular`, and `Upcoming` when available.
5. The user opens an event or gig detail page from the feed.
6. The user may save, sign up, or apply through route-owned detail plus overlay actions.

### Browse the Full Catalog

1. The user opens `Catalog` from the primary navigation.
2. The page displays the full browse surface for events and gigs.
3. The user narrows results with item-type, category, sort, and pagination controls.
4. The user opens a detail page from the browse results.
5. The user may save, sign up, or apply from the detail experience.

### Search for Events and Gigs

1. The user enters a keyword into the header search input or opens `Search`.
2. The application opens the `Search` page.
3. The page displays matching events and gigs for the current query.
4. The user refines the results with search filters.
5. The user either opens a detail page from the results or hands the query off to `AI` for more help.

### Manage Personal Content in You

1. The user opens `You` from the primary navigation.
2. The hub displays summary modules for collections, applications, and owned events and gigs.
3. The user navigates to `You` subpages such as collections, applications, or owned listings.
4. The user removes saved items, reviews application status, or edits owned content.

### Edit Personal Profile

1. The user opens the avatar menu.
2. The user chooses `My Profile`.
3. The application opens the dedicated profile page.
4. The user updates identity-facing profile fields and optionally previews the public profile.

### Chat with AI

1. The user opens `AI` from the shell.
2. The application opens the AI home page or a saved conversation route.
3. The user starts a new conversation or resumes a previous one.
4. The user sends a natural-language request.
5. The assistant responds with conversational guidance and structured event or gig results.
6. The user may confirm actions such as save or apply through overlay confirmations.
